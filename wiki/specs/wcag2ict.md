# WCAG2ICT

WCAG 2 を Web 以外の ICT (文書・ソフトウェア) に当てはめるためのガイダンス (Group Note)。リポジトリは [w3c/wcag2ict](https://github.com/w3c/wcag2ict)。

## 現状

- Level AAA の各 SC について、AG WG レビュー用の Issue が並行して進んでいる (例: [1.4.6 Contrast (Enhanced)](https://github.com/w3c/wcag2ict/issues/892)、[2.5.5 Target Size (Enhanced)](https://github.com/w3c/wcag2ict/issues/951))。
- AAA を別の節に分ける文書構成の変更も AG WG レビュー中 ([w3c/wcag2ict#900](https://github.com/w3c/wcag2ict/issues/900))。

## 最近の動き

- 2026-10 AAA の AG WG レビューを受けた編集 PR [w3c/wcag2ict#1004](https://github.com/w3c/wcag2ict/pull/1004) が merge。GreggVan は「non-web documents and/or non-web software」の and / or が文書内で不統一だと指摘する Issue を起票 ([#1005](https://github.com/w3c/wcag2ict/issues/1005)。本文によれば Claude で出現箇所を数えた)。
- 2026-10 pday1 の PR [w3c/wcag2ict#997](https://github.com/w3c/wcag2ict/pull/997) が merge。Level AAA の注の editor's note を通常の note にし、導入文を足した ([#989](https://github.com/w3c/wcag2ict/issues/989)、[TF 2026-09-17](https://www.w3.org/2026/09/17-wcag2ict-minutes.html#e098) に基づく)。AAA の AG WG レビューを受けた編集 PR [#1004](https://github.com/w3c/wcag2ict/pull/1004) と、2.4.13 Focus Appearance のレビュー Issue ([#978](https://github.com/w3c/wcag2ict/issues/978)) が更新。
- 2026-10 Level AAA の SC の AG WG レビュー Issue 約 15 件が更新 (例: [#995](https://github.com/w3c/wcag2ict/issues/995)、[#1000](https://github.com/w3c/wcag2ict/issues/1000)、[#894](https://github.com/w3c/wcag2ict/issues/894))。maryjom が Key Terms ([#1002](https://github.com/w3c/wcag2ict/issues/1002)) と全般 ([#1001](https://github.com/w3c/wcag2ict/issues/1001)) の編集コメントを更新。
- 2026-10 1.2.6 Sign Language (Prerecorded) の注記は通訳者を重視しすぎで、ろう者の手話提供者にも触れるべきという提案 ([w3c/wcag2ict#1003](https://github.com/w3c/wcag2ict/issues/1003)、mitchellevan)。ドイツの BITV が公共機関に手話コンテンツを求める例を挙げている。
- 2026-10 Level AAA の SC の AG WG レビュー Issue (`Please Review`) が引き続き更新された。例: [#892](https://github.com/w3c/wcag2ict/issues/892) (1.4.6)、[#903](https://github.com/w3c/wcag2ict/issues/903) (1.3.6)、[#896](https://github.com/w3c/wcag2ict/issues/896) (2.1.3)。
- 2026-09 AAA の SC 約 20 件の AG WG レビュー Issue が更新された (`Please Review` ラベル)。
- 2026-09 Key Terms 節の変更に対する編集上のコメント ([w3c/wcag2ict#1002](https://github.com/w3c/wcag2ict/issues/1002))。
