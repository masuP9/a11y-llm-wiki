# Web Accessibility Weekly 2026-W43

## 今週のハイライト

- **AGWG が WCAG 3 のスケジュールと要件の分類 (tier) を議論した (2026-10-20)。** 2028 年 1 月の CR、2027-11-27 の requirements freeze、CR 時点で refining に達しない要件は落とす、という説明があった。tier では「friction」の名称と定義、Core / Supplemental と impact tag の関係が割れ、採用された案はない。決議なし ([議事録](https://www.w3.org/2026/10/20-ag-minutes.html)。約半分のみ確認、[[specs/wcag-3]])。
- **COGA が WCAG 3 の exploratory provision を支持するコメントを多数起票した。** Interactive element importance indicated、Copying supported、No artificial time limits、Single flash など 10 件超 ([例: w3c/wcag3#931](https://github.com/w3c/wcag3/issues/931)、[#937](https://github.com/w3c/wcag3/issues/937))。COGA TF 自身は WCAG 3 の survey が使いにくいと指摘している ([議事録](https://www.w3.org/2026/10/19-coga-minutes.html))。
- **ARIA に `listview` role を追加する PR が出た。** interactive list 用で、[w3c/aria#2036](https://github.com/w3c/aria/issues/2036) (F2F ラベル) に対応する ([w3c/aria#2951](https://github.com/w3c/aria/pull/2951)、smhigley、[[specs/wai-aria]])。議論はこれから。
- **WCAG 2 の 3.3.2 Understanding を明確化する PR が merge された。** ラベル・説明の要否を段落に分けて書き直す内容で、[[people/scottaohara]] が出した ([w3c/wcag#4995](https://github.com/w3c/wcag/pull/4995)、[[specs/wcag-2]])。
- **NVDA 2026.3 が rc1 に進んだ (2026-10-21)。** beta6 (10-19) の後 ([release-2026.3rc1](https://github.com/nvaccess/nvda/releases/tag/release-2026.3rc1))。
