# Web Accessibility Weekly 2026-W40

## 今週のハイライト

- **ARIA WG: ARIA の radiogroup と `name` 付き radio を混ぜない方針を決議。** 2026-09-24 の会合で、author への MUST を足す方向と、ブラウザ側の修復 (名前付き group に格下げ) を検討することが決まった。radio のまとまりの計算がブラウザごとに違う問題への最初の決定になる ([議事録](https://www.w3.org/2026/09/24-aria-minutes.html)、[w3c/html-aam#598](https://github.com/w3c/html-aam/issues/598))。
- **WCAG 3: 9 月の WD に reporting tier が入り、要件のタグ付けが始まった。** 適合は単一の tier で、すべての core requirement が条件。AGWG は要件に harm / risk / barrier / friction などのタグを付ける作業を始めた。最初の snapshot の見込みは 2028-08-31 ([AGWG 2026-09-29 IRC](https://www.w3.org/2026/09/29-ag-irc))。
- **overlay と CAV の議論が新しい Issue に移った。** 79 コメントに及んだ [w3c/wcag#2750](https://github.com/w3c/wcag/issues/2750) が close され、「CAV への導線にラベルが無いと 2.4.6 / 3.3.2 違反か」という論点に絞って [w3c/wcag#5373](https://github.com/w3c/wcag/issues/5373) で続く。overlay 製品の適合判断に直接関わる。
- **ARIA Notify に導入文と i18n の例が入った。** [w3c/aria#2869](https://github.com/w3c/aria/pull/2869) の merge で、i18n-needs-resolution だった [#2828](https://github.com/w3c/aria/issues/2828) が close。
- **TPAC に向けて ARIA WG の議題候補が 17 件に。** AT Driver の ARIA charter への移管 ([#2915](https://github.com/w3c/aria/issues/2915))、Accessibility Compat Data の「supported」の定義 ([#2916](https://github.com/w3c/aria/issues/2916))、CSS で疑似要素に ARIA を付ける提案 ([#2921](https://github.com/w3c/aria/issues/2921)) など ([議事録](https://www.w3.org/2026/09/24-aria-minutes.html))。

## 今週のハイライト (追記分)

- **WCAG 3 の用語「programmatically」の整理が Issue の連続として始まった。** mcking65 が「programmatically determinable」の定義を「Exposed to user agents in an application programming interface」に置き換える案 ([w3c/wcag3#885](https://github.com/w3c/wcag3/issues/885)) と、これに伴う個別の provision の修正 Issue 7 件を起票した。WCAG 3 の多くの provision が使う語の意味に関わる。いずれもコメントは 1 件以下で、議論はこれから。
- **ARIA WG が translatable attributes の変更の merge を決議した (2026-10-01)。** [w3c/aria#2862](https://github.com/w3c/aria/pull/2862) が対象で、i18n-needs-resolution の [#2827](https://github.com/w3c/aria/issues/2827) が close。`aria-actions` ([#1805](https://github.com/w3c/aria/pull/1805)) は実装が揃うまで見送り ([議事録](https://www.w3.org/2026/10/01-aria-minutes.html))。
- **Android の AAM マッピング作業から仕様の曖昧さが報告された。** Chromium の dtsengchromium が、`role="time"` が TTS API に time / date / duration を区別して渡せないこと ([w3c/aria#2926](https://github.com/w3c/aria/issues/2926))、Core-AAM の「option inside combobox」の区別が不明確なこと ([w3c/core-aam#271](https://github.com/w3c/core-aam/issues/271)) を挙げた。ブラウザ実装が仕様の穴を見つける例。
- **WebMCP が APA に水平レビューを依頼した。** WebML CG は自己レビューを公開し、TPAC (2026-10-27) の F2F への参加を呼びかけている ([w3c/a11y-request#189](https://github.com/w3c/a11y-request/issues/189))。レビューの結論はまだ無い。
