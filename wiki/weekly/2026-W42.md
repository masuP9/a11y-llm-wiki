# Web Accessibility Weekly 2026-W42

## 今週のハイライト

- **AGWG が WCAG 3 の 2027・2028 年のスケジュールをレビューした (2026-10-13)。** [[people/rachaelbradley]] は、2027 年末までに公開レビュー用の snapshot、2028 年 1 月を目標に CR snapshot を示した。「CR snapshot」の意味と、2 回の CR snapshot が現実的かが議論され、明確なマイルストーンを求める声が出た。決議なし ([議事録](https://www.w3.org/2026/10/13-ag-minutes.html)。本文の一部のみ確認、[[specs/wcag-3]])。
- **COGA が WCAG 3 の provision に対するコメントを一括して起票した。** lbeaze が Focus retained、Pointer focus indicated の例外、Expected Behavior に core requirement が無いこと、Support available など 8 件を起票した ([例: w3c/wcag3#916](https://github.com/w3c/wcag3/issues/916)、[#921](https://github.com/w3c/wcag3/issues/921))。COGA TF は 10-22 に exploratory provisions の単発レビュー会合を開く方針 ([議事録](https://www.w3.org/2026/10/12-coga-minutes.html))。
- **WCAG 3 の WD に対し、GreggVan が keyboard focus への統一、Flashing の例外削除、自動再生音声の provision 追加などを連続して提起した。** 起票直後で議論はこれから ([例: w3c/wcag3#908](https://github.com/w3c/wcag3/issues/908)、[#913](https://github.com/w3c/wcag3/issues/913)、[#911](https://github.com/w3c/wcag3/issues/911))。
- **ARIA WG が TPAC 前の最終会合を開いた (2026-10-15)。** RESOLUTION 行はなく、video `poster` 要素の mapping は HTML-AAM 側で扱い、aria-keyshortcuts の macOS mapping は jcraig がレビューする。HTML-AAM の good first issue では AI の成果物に人間のレビューが必須とされた ([議事録](https://www.w3.org/2026/10/15-aria-minutes.html)、[[specs/wai-aria]])。
- **WCAG 2 の Understanding を直す編集 PR が [[people/patrickhlauke]] から連続して出た。** 4.1.2 の「correct」を「appropriate」に ([w3c/wcag#5407](https://github.com/w3c/wcag/pull/5407))、4.1.2 の対象を利用者が設定できる state / property に限る PR ([#5399](https://github.com/w3c/wcag/pull/5399))、`role` と「programmatically determined」の例の更新など。AGWG は WCAG 2 の変更案の新しいバッチを 10-19 までレビューに出している ([[specs/wcag-2]])。

## 議事録

- **COGA TF 2026-10-12** ([議事録](https://www.w3.org/2026/10/12-coga-minutes.html)): RESOLUTION 行なし。TPAC の breakout 提案は Len を chair として登録し、AI の利用の教訓を発表する。WCAG 3 の exploratory provisions を 10-22 に単発で確認する。functional statements は元の提案を維持する。
- **AGWG 2026-10-13** ([議事録](https://www.w3.org/2026/10/13-ag-minutes.html)): 取得できた範囲に RESOLUTION 行なし。WCAG 2 の変更案を 10-19 までレビュー、WCAG 3 の 2027・2028 年のスケジュール、要件の分類 (physical harm は「immediate」を見直す、risk の「reputational」は曖昧という意見)。本文の約半分のみ確認。TPAC (ダブリン) の夕食会は 10-26。
- **ARIA APG TF 2026-10-14** ([議事録](https://www.w3.org/2026/10/14-aria-apg-minutes.html)): RESOLUTION 行なし。11-05 に準備済みの PR を公開予定。contrast setting とランドマークの更新は含まない。
- **APA WG 2026-10-14** ([議事録](https://www.w3.org/2026/10/14-apa-minutes.html)): RESOLUTION 行なし。TPAC の breakout への割り当て。CSS Color 4 のレビュー期限は 2026-12-09。css-content で画像の読み込み失敗時に alt を描画する案に賛成が多い。
- **ARIA WG 2026-10-15** ([議事録](https://www.w3.org/2026/10/15-aria-minutes.html)): RESOLUTION 行なし。PR / Issue の triage と TPAC の最終準備。
