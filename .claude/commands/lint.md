# /lint

1. `wiki/` の全ページを走査し、次を修正する。
   - ページ間の矛盾 (仕様の status、日付、決定事項)
   - `[[...]]` リンク切れ、index.md への未登録ページ
   - 「現状」が 3 か月以上更新されていない spec ページ → 最新の TR / ED を WebFetch で確認して更新
   - 出典リンクの無い記述 → 出典を探すか、削除する
2. 直近 4 回分の `raw/*/collected.md` の「取得失敗」を集計し、継続して失敗しているソースについて
   `sources.yml` の修正案 (正しい URL・ラベル名) を調べて `wiki/lint-report.md` に書く。sources.yml 自体は変更しない。
3. ノイズが多いソース (毎週「低」ばかりのもの) と、取りこぼしが疑われる領域を `wiki/lint-report.md` に書く。
4. `wiki/log.md` に `- <日付> lint: 修正 N 件` を追記する。
